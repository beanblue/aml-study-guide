# 反洗钱规则库 - 原文展示文件结构分析报告

## 分析范围

`/workspace/aml-study-guide/regulations/` 目录下15个仅有原文展示（无条文卡片化）的HTML文件。

## 核心结论

**全部15个文件均为"段落式/通知式"编写，无一使用"第X条"作为自身条文编号。**

文件中出现的"第X条"均为引用其他法律法规（如"根据《反洗钱法》第X条"、"将《管理办法》第X条修改为..."），并非文件自身的条文编号。因此，**这15个文件均不适合按"逐条卡片"（第1条、第2条...）方式拆分**，但均可按"段落/章节卡片"方式拆分。
